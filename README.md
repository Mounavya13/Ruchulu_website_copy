# Mr. Biriyaniwala

A faithful, scroll-controlled recreation of the supplied Mr. Biriyaniwala render.

## Run locally

```bash
npm start
```

Open `http://127.0.0.1:4173`.

## Features

- The supplied 40-second 3D render is scrubbed directly by page scroll
- Transparent navigation hotspots make the filmed menu interactive
- A responsive six-category menu with working tabs and keyboard navigation
- Keyboard, mouse-wheel, trackpad, and touch scrolling
- Exact typography, dish animation, ingredient motion, cooking scenes, and visit sequence from the reference
- Native 1152×720 (8:5) video ratio preserved on desktop and mobile
- Reduced-motion and keyboard accessibility support
- Lightweight static HTML, CSS, and JavaScript with no runtime dependencies
